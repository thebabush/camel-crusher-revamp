# Fonts

Source: https://github.com/google/fonts/tree/main/ofl/ (archivo,
bricolagegrotesque and ibmplexmono). Each family's SIL Open Font License is
included here.

Archivo Medium and Black Italic were instantiated from the upstream variable
TTFs with fontTools varLib.instancer at width 100 and weights 500 and 900.
Bricolage Grotesque Bold and ExtraBold were instantiated at optical size 14,
width 100 and weights 700 and 800. IBM Plex Mono Regular is an upstream static TTF.
The four instantiated fonts were subset with pyftsubset to basic and extended Latin,
Latin-1 and general punctuation (U+0020–007E, U+00A0–00FF, U+0100–017F,
U+2000–206F), retaining layout features.
